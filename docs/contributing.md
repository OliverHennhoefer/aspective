# Contributing

aspective has a narrow scope and a high bar: an estimator belongs here when
it is a variant of a classic estimator, comes from a peer-reviewed paper that
compares it with the vanilla version, is not already in scikit-learn or PyOD,
and passes the [benchmark gate](benchmarks.md).

Have a candidate in mind? Open an
[estimator proposal](https://github.com/OliverHennhoefer/aspective/issues/new?template=estimator_proposal.md).
The full guide, with the development setup and the checklist for a new
estimator, is in
[CONTRIBUTING.md](https://github.com/OliverHennhoefer/aspective/blob/main/CONTRIBUTING.md).
